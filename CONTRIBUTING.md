# Contributing

Maintained by 赵兴华 / Steven Zhao·China（ORCID 0009-0001-0512-1237）.

1. **Issues**: state the file/section and the problem; for factual claims attach an official source link with verification date.
2. **Suggestions**: describe the target audience and intended use.
3. **Code/scripts**: follow the repository LICENSE; self-test before submitting and include run instructions.

## Rules

- Factual/regulatory content must cite sources and a verification date; write "to be verified" when unsure — never estimate.
- Theoretical texts and methodology statements are All Rights Reserved; contributions do not change ownership.
